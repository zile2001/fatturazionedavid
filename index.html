Sulla tecnologia

FatturAttiva è una pagina statica: lettura Excel, generazione XML, validazione e PDF avvengono interamente nel tuo browser, senza alcuna chiamata di rete. Il file Excel non viene mai inviato altrove.

Lo standard di riferimento è la Specifica Tecnica FatturaPA v1.2.1 (Sogei / Agenzia delle Entrate).

Validazione

La pagina esegue i controlli più rilevanti del Sistema di Interscambio (serie 00400). Resta sempre opportuno un riscontro col gestionale del commercialista prima della trasmissione.

Note

I dati anagrafici stampati sul PDF di cortesia provengono direttamente dal file Excel caricato; il logo è fisso (SACOPH).
